# 🎬 Forgatókönyv Projekt

Ez egy filmforgatókönyv-projekt sablon GitHub-hoz.

## Mappastruktúra
- `script/` – a forgatókönyv verziói
- `notes/` – jegyzetek, karakterek, ötletek
- `research/` – háttéranyagok, inspirációk
- `translations/` – fordítások
